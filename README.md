## FAQ

**Does this VPN slow down my internet?**  
Some overhead is normal. Pick the nearest server first; switch protocol only if you need more speed or stability.

**What does “No-Logs policy” mean here?**  
It means you should expect the service not to store activity logs. This guide covers what to verify (policy language, audits, and what’s still visible like payment metadata).

**Why is the Kill Switch non-negotiable?**  
If the tunnel drops, your traffic can leak over your normal connection. Kill Switch blocks that by default.

**Can I choose a specific country/server?**  
Yes. Use **Global Servers** for location selection, but prioritize latency for daily use and only move locations when you need it.
